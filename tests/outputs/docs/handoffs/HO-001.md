# HO-001：01 → 02 交接演练
版本：演练 v2（仅复核自动化配置差异分支）；状态：交接条件不足，未切换、未归档。
题设：当前总控为旧01，02仅回复“收到”；ignored数据库和依赖仅位于旧附着tree；实时周期为09:00，旧记录为30分钟；用户已授权接班、改绑及归档。

## 具体下一步与条件
1. 01核旧tree写入状态与必要资产清单，准备不会随01归档的位置。活跃数据库使用一致性备份或已有授权的停写点；不裸复制活动数据库。保全数据库、依赖及必要源码，核摘要、实际可读性和符号链接终点；若停写需新增授权，只处理这一缺口。
2. 01让02只读交接包和独立资料，回执职责、路径/版本、未完项、第一步、缺口，并执行必要低成本运行检查；“收到”不算接班通过。
3. 01查自动化现读完整配置、任务身份和原用户授权，记录09:00与旧30分钟的差异，按以下两分支处理：
   - 可推进分支：若仅旧记录过时，实时完整配置可核，且与原用户授权无冲突，则保留现读09:00及其他字段，仅在授权内改目标为02并读回。标明旧记录差异与实际核查范围，不必追溯每次旧修改，不因历史过时本身阻塞。题设仅给出现读时间，不能据此假定完整配置和授权均已核验。
   - 必须先解决分支：涉及用户明确禁令、预算/停止条件、未知任务身份或并发写入风险时，不将差异当作普通旧记录过时；先解决关键冲突再改绑/切换。当前旧主责和未归档状态保留。
4. 在已授权范围内改绑02，沿用现读提示、周期、状态及其余字段，读回目标与配置。改绑成功和首次定时执行成功分开记录；本演练不声称任一成功。
5. 独立保全、02实质回执及可运行性、自动化承接、写入协调均通过，才切换唯一主责和现行入口。
6. 归档前明确由已承接的02负责最终归档01及归档后复核。02确认原生归档状态，再核独立资料路径和实际可运行性；全部有证据后才标完成。没有实际承接的复核方时保留01，不自归档后承诺检查。

## 当前可声称结论
仅已拟定交接步骤；所有原生操作及保全动作均未执行。不能声称02接班、调度改绑或01归档完成。

## 第4步针对性反例（v2）
假设其他交接条件已通过；可核的用户原话为“周检继续暂停，未经我再次明确批准不得恢复自动巡检；换班可更换接收会话”。旧记录为暂停、30分钟，现读完整配置却为ACTIVE、09:00，未找到恢复授权。
判断：命中明确禁令，不能把ACTIVE配置原样改到02并声称承接完成，也不能把本次换目标授权解释为恢复许可。先按可核授权解决运行状态冲突并读回；缺少必要权限或证据时保持交接未完成，不切换、不归档。即使配置可完整读取，禁令冲突仍阻止进入“仅历史过时”分支。此为文本反例，未操作调度。

## 被替代的v1判断
