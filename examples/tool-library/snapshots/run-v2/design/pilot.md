# 借物小站试点方案

版本：design-v2（D2，2026-10-19）；库存同版。仅补Q1-02台账异常流程及同步版本，替代design-v1；旧冻结版保留。输入：brief-v1、冻结 research-v1（`../snapshots/research-v1/sources.md`）；研究摘要 SHA256 已与 `../receipts/research-freeze.json` 核对一致。本文仅供虚构演练，待独立复验。

## 依据与设计选择

**外部事实仅按冻结研究转述**：S1区分预约与取还；S2要求检查、报损及不安全即停用；S3免费使用仍可能有押金和异常费用；S4要求停用不安全工具、允许正常磨损、发送逾期通知；S5要求在工具馆开放时归还并规定待取期限。这些机构规则不证明本项目效果。

**冲突保留**：S4第8项同时写“续借一次”和“最多连续两次”，research-v1认为口径冲突，本方案不采用其次数。

**简报设定**：20件虚构低风险手工具、人工确认、免收费、无押金。**以下全部为设计选择**：借期自交接起168小时；待取24小时；不续借、不预订未来时段、不排队；逾期不收费。取消、逾期或损坏均不另收费用。低风险为选型目标，实际安全分类未验证。

## 管理员流程（仅模拟）

1. 开始及每次受理前，检查待取到期和逾期；同一管理员串行操作同一份库存，保存并重读后才确认。借用者仅用虚构代号，不录真实个人信息。
2. 预约：仅“可借且安全已核验”受理；按管理员受理顺序，先写唯一流水号、借用代号、预约时刻、待取截止，再设“待取”。相同代号重提，返回原流水；另一代号申请同件则拒绝，不能覆盖。保存失败不确认，恢复后先核原记录。
3. 取消或达到待取截止仍未交接：登记原因，归档该次记录后清空活动字段，恢复可借。恰好截止也算失效，取用者须重新预约。
4. 借出：未到待取截止，核流水、代号和实物编号，双方模拟核完整与安全；通过后填借出时刻和到期时刻，改“借出”。发现异常改“待检”，不交付。说明用途、停用报损和归还交接要求。
5. 逾期：当前时刻大于到期、且尚未交还即逾期；正常借出行改“逾期”，记一次模拟提醒，之后每天最多一次。到期瞬间未算逾期。不延长到期、不再次借出；持续未还由管理员记异常，不自动结案。
6. 归还：管理员模拟当面接收、填归还时刻并改“待检”，再检查完整、安全及原有缺损。正常磨损但功能安全则记检查通过；损坏、缺件或不确定则保留待检，无法恢复则停用。通过后归档、清空活动字段再可借；放门口或口头称归还不算交接。
7. 借用中报损：记状况为“异常”，告知立即停用并安排归还，保留借出/逾期状态及到期记录；不要求冒险操作。归还后待检，复核通过才可借。无赔偿自动判定；本演练不处理真实伤害或责任争议。

## 台账异常（Q1-02，优先于正常流程）

1. **暂停**：漏记、ID不存在或账实不符时，暂停该件预约确认、交付、释放及催还提醒。先留异常日志，抄存原状态、状况及七个活动字段（含空值），再记condition=异常；无未归还借出时改待检，否则保留借出/逾期及活动字段。无行则在本文末尾追加临时异常条目，不凭口述建库存或分配新ID。日志含所报ID（无则注明）、发现时刻、管理员代号、现象及暂停范围。
2. **核实**：管理员核实实物编号、冻结库存、原流水与模拟交接日志；不凭口头称已还或货架有物认定归还。编号、时间或依据不明则保持暂停、记缺口，不清账不推断。
3. **更正留痕**：更正前追加所改字段旧值（含空值）、新值、原状态/流水、依据位置、实际事件时刻、更正时刻及管理员代号。无行条目查明后迁入正确行notes，本文保留迁入位置。确认漏记才补实际归还时刻并进入待检，不用更正时刻冒充；缺失行仅按冻结20件中的原ID恢复，保留原流水，不能新增第21件。
4. **恢复**：重读核对账实、日志及流水唯一性，按核实的安全状况恢复condition并记复核结论。确认仍借出则按原到期恢复借出/逾期及提醒；已归还则按第6条检查、归档后可借；未借出且原待取仍有效则恢复待取，已取消/到期则按第3条关闭，无占用则检查通过后可借。安全状况未核实或复核未通过则保持暂停；查无此ID的请求拒绝并保留条目，不影响其他已核实物品。

## 库存字段与约束

`inventory.csv`每行一件实物；初始全部待检、未核验，未声称已实际检查。仅模拟检查通过才转可借。

| 字段 | 含义与约束 |
| --- | --- |
| item_id/name | 唯一实物编号/名称；不复用编号 |
| status | 待检、可借、待取、借出、逾期、停用；停用仅复核后转待检 |
| condition | 未核验、完好、正常磨损、异常；可借前须完好或已确认安全的正常磨损 |
| active_record_id/borrower_ref | 当前流水/虚构借用代号；每件最多一个有效流水 |
| reserved_at/pickup_deadline | 预约时刻/其后24小时 |
| borrowed_at/due_at/returned_at | 实际模拟交接/其后168小时/管理员接收时刻 |
| checked_at/notes | 最近模拟检查时刻/追加事件日志，不覆盖旧内容 |

所有时刻用带`+08:00`的ISO 8601格式，空值表示未发生。活动字段指流水至归还时刻的七列；归还待检时保留，只有关闭该次记录才清空。关闭前将七列原值、操作时刻、管理员虚构代号及原因追加至notes；检查、拒绝、提醒亦追加日志。任何未交还流水均按原到期时刻判断逾期；不得清除未归还责任记录。可借/停用无未结流水；异常不能直接可借。

人工单写与notes日志只适合本次20件演练；需求、成本、安全和本地法律适用性仍未知，未证明实际运营可行。下一主责为总控冻结design-v2，再交Q2独立复验；本轮修订后停止，不自行迭代。
