# R1 一手来源核验

版本：research-v1；输入：brief-v1、RUN-001、冻结 Skill 0.2.0。访问日期均为 **2026-10-19（Asia/Shanghai）**；实际通过网页工具打开正文，非仅据搜索摘要。覆盖3家运营机构、5个官方页面。以下“事实”仅指该机构公开表述，未验证实际执行或效果；“影响”均为供方案角色选择的研究建议，尚非冻结规则。

## S1：预约与取还

[Library of Things — How borrowing works](https://www.libraryofthings.co.uk/how-borrowing-works)

- 事实：可在线查询、预约，再到自助柜取还；有可用物品时可当天领取（Browse and reserve、Collect and return）。
- 边界：英国收费租借、自助柜模式；不能证明本社区需求、人工管理效率或免费模式可持续。
- 影响：试点应分开记录“预约确认”与“实际借出”，确认时核可用性；不据此引入自助柜。

## S2：续期与损坏

[Library of Things — Terms of Borrowing](https://www.libraryofthings.co.uk/terms-of-borrowing)

- 事实：Borrowing / Member Responsibilities 第2项：修改归还日期须未逾期，且新归还日之前或当天无他人预约；第4、7、8项要求及时报损、取用时检查完整与安全，变得不安全即停用。
- 边界：这是该公司的合同规则；收费、赔偿、保险及免责文字不构成本试点的法律依据。
- 影响：人工续期也应核后续预约；交接记录原有缺损，报损后暂停该物品流转并由管理员复核。

## S3：免费与会员条件

[SE Seattle Tool Library — Membership](https://setools.org/membership/)

- 事实：多数工具可借一周，通常在无人等待时续借；使用免费、年度捐款自愿。入会需表格及照片证件；部分工具可能要求押金，逾期或维护费用也可能适用（To Begin Borrowing Tools、Notes Regarding Membership）。
- 边界：此会员制包含志愿服务与捐款支持；“免费使用”不等于全面免押金、免异常费用，也不能推出本试点成本为零。
- 影响：可借鉴“无等待者才续借”；本试点无押金与免收费须明确标为内部设定，不能声称照搬该机构。

## S4：逾期与安全异常

[Berkeley Public Library — Borrowing Tools](https://www.berkeleypubliclibrary.org/locations/tool-lending-library/borrowing-tools)

- 事实：第5项要求不安全或失修即停用并归还；第7项借期7天，归还状态允许正常磨损；第9、10项分别允许缺货排队预约、规定发逾期通知。
- 边界：资格限本市成年居民或业主，规则含赔偿与追偿安排；不能直接移植为本试点政策。第8项同时写续借一次、最多连续两次，次数口径有冲突，不采用。
- 影响：区分正常磨损与损坏；设置逾期提醒及人工异常处理，但具体期限、次数及责任处理须由方案另定。

## S5：归还与待取期限

[Berkeley Public Library — Tools FAQ](https://www.berkeleypubliclibrary.org/locations/tool-lending-library/tools-faq)

- 事实：How do I borrow tools 说明到货通知后保留3天；How do I return tools 要求开放时间到工具馆归还，不可放图书还书口或闭馆时留在门外。
- 边界：3天及现场流程属于该馆；不外推其营业时间或当前服务可用性。
- 影响：试点需定义待取失效及人工确认归还；收到物品后检查通过再恢复可借，防止无人交接即释放库存。

## 设定、缺口与交接

20件低风险手工具、虚构社区、人工确认、免费无押金均来自 brief-v1，非外部研究发现。重复预约互斥、库存状态字段、借期及逾期阈值仍由方案设计并明确标记。未验证真实需求、成本、安全分类及本地法律适用性；无访谈、外联或经营行为。
