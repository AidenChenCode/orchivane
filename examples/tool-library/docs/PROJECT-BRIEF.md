# 借物小站项目简报（公开摘要）

版本：brief-v1-public；原实验日期：2026-10-19。用户要求用全新示例实测 Session Control 从调研沟通到创建 session、派工和验收，明确开源对象为 Session Control，并将案例选择交给总控。以下角色与参数由总控确定；没有真实社区访谈。此公开摘要不包含用户聊天原文或会话ID，也不向读者授予原实验的工具权限。

虚构20件低风险手工具，人工确认、免费无押金。交付为至少3个一手来源、借还方案、20行库存CSV及独立验收。需要区分研究事实和设计选择，覆盖正常借还、重复预约、逾期、损坏与台账异常。没有代码、网站、真实借用、收费或部署。

总控保管授权、版本与索引；调研主责外部证据，方案主责转译和内部规则，验收独立检查。三角色用来测试真实依赖与交接，不证明这个小任务需要多会话或更省成本。初始没有专业session，当前总控创建了三个新原生会话。

R1与Q0可独立做，D0先只读承接；R1冻结后D1，D1冻结后Q1，最多一轮D2/Q2。无论第二轮结果如何，停止并报告。旧冻结输入不得覆盖。
